\ifEn
    \section{Modified Secant Condition}
\else
    \section{修正セカント条件}
\fi
\label{sec:background_modified_secant}

\ifEn
    This section explains the modified secant condition, a modification of the standard secant condition. The modified secant condition incorporates function value information in addition to gradient information, leading to more accurate Hessian approximations.
\else
    本節では、通常のセカント条件の修正版である修正セカント条件について説明します。修正セカント条件は勾配情報に加えて関数値情報を取り込み、より正確なヘッセ行列の近似を実現します。
\fi

\ifEn
    \subsection{Derivation of the Modified Secant Condition}
\else
    \subsection{修正セカント条件の導出}
\fi

\ifEn
    Although the secant condition is widely used in many quasi-Newton methods, it can fail to capture the curvature of the objective function accurately because it only utilizes gradient information. We illustrate this limitation in \cref{fig:msec_overview}.
\else
    セカント条件は準ニュートン法で広く用いられていますが、勾配情報のみを活用するため、目的関数の曲率を正確に捉えられないことがあります。このことを\cref{fig:msec_overview}で説明します。
\fi
\ifEn
    In \cref{fig:msec_overview}, we have two points $x_k$ and $x_{k+1}$ where function values and gradients are already known. We see that the ideal quadratic model constructed from the exact Hessian fits well around the new point $x_{k+1}$, leading to a better convergence behavior. However, the standard secant condition uses only gradient information and ignores function values. Consequently, it may significantly misestimate curvature, leading to a poor approximation of the true objective function.
\else
    \Cref{fig:msec_overview} において、関数値と勾配が既知の2点 $x_k$ と $x_{k+1}$ があるとします。正確なヘッセ行列から構築された理想的な二次モデルは、新しい点 $x_{k+1}$ の周りでよくフィットしており、より良い収束挙動をもたらすことが分かります。しかし、勾配のみを用いて課される標準的なセカント条件で作られるモデルでは、関数値の情報が無視されます。よって、曲率を大きく誤る可能性があり、真の目的関数の近似が悪くなります。
\fi

\ifEn
    We can overcome this limitation by utilizing the function values. The basic idea is illustrated in \cref{fig:cubic_interpolation}. Even when the gradients are the same at two points $x_k$ and $x_{k+1}$, natural interpolation of function values differs depending on the function values $f(x_k)$ and $f(x_{k+1})$. This observation motivates the modified secant condition, which incorporates function value information to improve Hessian approximation.
\else
    この問題は、関数値を利用することで克服できます。基本的な考え方は \cref{fig:cubic_interpolation} に示した通りです。2 点 $x_k$ と $x_{k+1}$ で勾配が同じであっても、適切な補間は関数値 $f(x_k)$ と $f(x_{k+1})$ によって異なります。この観察こそが、関数値情報を取り込んでヘッセ行列の近似を改善する修正セカント条件の動機を端的に示しています。
\fi

        \else
            修正セカント条件の基本的な考え方。$x_k$ と $x_{k+1}$ で同一の勾配を持つが異なる関数値を持つ場合、適切な補間は異なります。
        \fi

\ifEn
    In the following, we present two well-known modified secant conditions.
\else
    以下では、2つの既知の修正セカント条件を提示します。
\fi

\ifEn
    \subsubsection{Function-Value-Matching Modified Secant Condition}
\else
    \subsubsection{関数値一致の修正セカント条件}
\fi
\label{subsubsec:yuan}

\ifEn
    The first modification enforces the quadratic model to match the function value at the previous point~\citep{yuanModifiedBFGSAlgorithm1991,weiNewQuasiNewtonMethods2006, babaie-kafakiModifiedBFGSAlgorithm2011}. Let us consider an alternate model with a different approximate Hessian $B_{k+1}^{\mathrm{F}}$:
\else
    最初の修正は、二次モデルが前の点での関数値と一致することを強制します~\citep{yuanModifiedBFGSAlgorithm1991,weiNewQuasiNewtonMethods2006, babaie-kafakiModifiedBFGSAlgorithm2011}。異なる近似ヘッセ行列 $B_{k+1}^{\mathrm{F}}$ を持つ別のモデルを考えます。
\fi
\begin{equation*}
    m_{k+1}^{\mathrm{F}}(x) \coloneqq f(x_{k+1}) + \nabla f(x_{k+1})^\top (x - x_{k+1}) + \frac{1}{2} (x - x_{k+1})^\top B_{k+1}^{\mathrm{F}} (x - x_{k+1}).
\end{equation*}
\ifEn
    We require this model to satisfy
\else
    ここでは、
\fi
\begin{equation*}
    m_{k+1}^{\mathrm{F}}(x_k) = f(x_k),
\end{equation*}
\ifEn
    which enforces that the function value at the previous point is correctly modeled.
\else
    つまり、前の点での関数値が、モデル関数でも一致することを課します。
\fi

\ifEn
    Let us derive the corresponding modified secant condition for $B_{k+1}^{\mathrm{F}}$. Substituting the definition of $m_{k+1}^{\mathrm{F}}$ and using $s_k = x_{k+1} - x_k$, the condition becomes
\else
    対応する修正セカント条件を $B_{k+1}^{\mathrm{F}}$ に対して導出しましょう。$m_{k+1}^{\mathrm{F}}$ の定義を代入し、$s_k = x_{k+1} - x_k$ を使用することで、条件は以下になります。
\fi
\begin{align*}
    f(x_k) & = f(x_{k+1}) + \nabla f(x_{k+1})^\top (x_k - x_{k+1}) + \frac{1}{2} (x_k - x_{k+1})^\top B_{k+1}^{\mathrm{F}} (x_k - x_{k+1}) \\
           & = f(x_{k+1}) - \nabla f(x_{k+1})^\top s_k + \frac{1}{2} s_k^\top B_{k+1}^{\mathrm{F}} s_k.
\end{align*}
\ifEn
    Now, instead of the standard secant condition, we assume a modified form with an additional term involving the identity matrix:
\else
    ここで、通常のセカント条件の代わりに、次のように単位行列による修正を加えた形を仮定します。
\fi
\begin{equation*}
    \left(B_{k+1}^{\mathrm{F}} + \sigma_k^\mathrm{F} I \right) s_k = y_k.
\end{equation*}
\ifEn
    Here, $\sigma_k^\mathrm{F} \in \mathbb{R}$ is a scalar to be determined as follows. Substituting this equation yields
\else
    ここで、$\sigma_k^\mathrm{F} \in \mathbb{R}$ は以下で決定するスカラーです。この方程式を代入すると、以下が得られます。
\fi
\begin{equation*}
    f(x_k) = f(x_{k+1}) - \nabla f(x_{k+1})^\top s_k + \frac{1}{2} s_k^\top y_k - \frac{\sigma_k^\mathrm{F}}{2} \left\lVert s_k \right\rVert^2.
\end{equation*}
\ifEn
    Solving for $\sigma_k^\mathrm{F}$ and using $y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$, we obtain
\else
    $\sigma_k^\mathrm{F}$ について解き、$y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$ を使用することで、以下を得ます。
\fi
\begin{align*}
    \sigma_k^\mathrm{F} & = \frac{2(f(x_{k+1}) - f(x_k)) - (2\nabla f(x_{k+1}) - y_k)^\top s_k}{\left\lVert s_k \right\rVert^2}           \\
                        & = \frac{2(f(x_{k+1}) - f(x_k)) - (\nabla f(x_{k+1}) + \nabla f(x_k))^\top s_k}{\left\lVert s_k \right\rVert^2}.
\end{align*}
\ifEn
    Therefore, the modified secant condition becomes
\else
    従って、修正セカント条件は以下になります。
\fi
\begin{equation*}
    B_{k+1}^{\mathrm{F}} s_k = \hat{y}^{\mathrm{F}}_k \coloneqq y_k + \frac{2(f(x_k) - f(x_{k+1})) + (\nabla f(x_{k+1}) + \nabla f(x_k))^\top s_k}{\left\lVert s_k \right\rVert^2} s_k.
\end{equation*}
\ifEn
    By using this modified $\hat{y}^\mathrm{F}_k$ instead of $y_k$ in various quasi-Newton updates, we can incorporate function value information while keeping almost the same algorithm. Additionally, since condition $s_k^\top y_k > 0$ is important for maintaining positive definiteness in BFGS update, we can consider the following modification to ensure that the inner product with $s_k$ remains positive:
\else
    よって、各種の準ニュートン法の更新において、$y_k$ の代わりに、この修正された $\hat{y}^\mathrm{F}_k$ を使用することで、殆ど同じアルゴリズムのまま、目的関数値の情報を取り込むことができます。また、特にBFGS更新で $s_k^\top y_k > 0$ という条件は正定値性を保つために使われるなど重要な性質である為、$s_k$ との内積が正であることを保証した、次の修正も考えられます。
\fi
\begin{equation*}
    B_{k+1}^{\mathrm{F}'} s_k = y_k + \frac{\max(0, 2(f(x_k) - f(x_{k+1})) + (\nabla f(x_{k+1}) + \nabla f(x_k))^\top s_k)}{\left\lVert s_k \right\rVert^2} s_k.
\end{equation*}
\ifEn
    This is the function-value-matching modified secant condition. Refer to \cref{fig:yuan_msec} for an illustration.
\else
    これが関数値一致の修正セカント条件です。具体例として\cref{fig:yuan_msec} も参照してください。
\fi

\begin{figure}[t]
    \centering
    \includegraphics[width=0.7\textwidth]{../imgs/modified_secant/trial_2.pdf}
    \caption{
    \ifEn
        Function-value-matching modified secant equation. The function values $f(x_{k})$ and $m_{k+1}^{\mathrm{F}}(x_{k})$ are matched at the previous point $x_{k}$.
    \else
        関数値一致の修正セカント方程式。前の点 $x_{k}$ での関数値 $f(x_{k})$ と $m_{k+1}^{\mathrm{F}}(x_{k})$ が一致している。
    \fi
    }
    \label{fig:yuan_msec}
\end{figure}

\ifEn
    \subsubsection{Cubic-Augmented Modified Secant Condition}
\else
    \subsubsection{三次項による修正セカント条件}
\fi
\label{subsubsec:zhang}

\ifEn
    The second modified secant condition introduces a cubic term to the model, allowing simultaneous satisfaction of both the function value and the gradient matching at the previous point~\citep{zhangNewQuasiNewtonEquation1999, zhangPropertiesNumericalPerformance2001,yabeLocalSuperlinearConvergence2007}.
\else
    2つ目の修正セカント条件では、モデルに三次項を導入し、前の点での関数値と勾配の両方の一致を同時に満たすことを可能にします~\citep{zhangNewQuasiNewtonEquation1999, zhangPropertiesNumericalPerformance2001,yabeLocalSuperlinearConvergence2007}。
\fi
\ifEn
    Let $T_{k+1} \in \mathbb{R}^{n \times n \times n}$ be the third-order derivative tensor of $f$ at $x_{k+1}$ such that
\else
    $T_{k+1} \in \mathbb{R}^{n \times n \times n}$ を、以下を満たす $x_{k+1}$ での $f$ の3階微分テンソルとします。
\fi
\begin{equation*}
    s_k^\top (T_{k+1} s_k) s_k = \sum_{i,j,l=1}^n \partial_{ijl} f(x_{k+1}) s_k^{(i)} s_k^{(j)} s_k^{(l)}.
\end{equation*}
\ifEn
    Here, $\partial_{ijl} f$ denotes the third derivative of $f$ with respect to $x_i$, $x_j$, and $x_l$, and $s_k^{(i)}$ is the $i$-th component of the vector $s_k$. We introduced this tensor solely for analysis purposes, and it will be eliminated from the final formula.
\else
    ここで、$\partial_{ijl} f$ は $f$ の $x_i$、$x_j$、および $x_l$ に対する3階微分を表し、$s_k^{(i)}$ はベクトル $s_k$ の第 $i$ 成分です。このテンソルは解析目的でのみ導入しており、最終的な式からは除去されます。
\fi

\ifEn
    By incorporating this tensor term, we can define the following model:
\else
    このテンソル項を組み込むことにより、以下のモデル関数を定義できます。
\fi
\begin{align*}
    m_{k+1}^\mathrm{C}(x) \coloneqq{} & f(x_{k+1}) + \nabla f(x_{k+1})^\top (x - x_{k+1}) + \frac{1}{2} (x - x_{k+1})^\top B_{k+1}^{\mathrm{C}} (x - x_{k+1}) \\*
                                      & + \frac{1}{6}(x - x_{k+1})^\top (T_{k+1} (x - x_{k+1})) (x - x_{k+1}).
\end{align*}
\ifEn
    With this model, we can enforce both function value and gradient matching at the previous point $x_k$. Specifically, we require
\else
    このモデルを使用して、前の点 $x_k$ での関数値と勾配の両方の一致を強制できます。具体的には、以下を要求します。
\fi
\begin{equation*}
    \begin{dcases}
        m_{k+1}^\mathrm{C}(x_k) = f(x_k), \\
        \nabla m_{k+1}^\mathrm{C}(x_k) = \nabla f(x_k).
    \end{dcases}
\end{equation*}
\ifEn
    By substituting the definition of $m_{k+1}^\mathrm{C}$ and using $s_k = x_{k+1} - x_k$, we can rewrite these conditions as
\else
    $m_{k+1}^\mathrm{C}$ の定義を代入し、$s_k = x_{k+1} - x_k$ を使用することで、これらの条件を以下のように書き直せます。
\fi
\begin{align*}
    f(x_k)        & = f(x_{k+1}) - s_k^\top \nabla f(x_{k+1}) + \frac{1}{2} s_k^\top B_{k+1}^{\mathrm{C}} s_k - \frac{1}{6} s_k^\top (T_{k+1} s_k) s_k, \\
    \nabla f(x_k) & = \nabla f(x_{k+1}) - B_{k+1}^{\mathrm{C}} s_k + \frac{1}{2} (T_{k+1} s_k) s_k.
\end{align*}
\ifEn
    Rearranging and multiplying both sides by $3$ for the first equation, and taking the inner product with $s_k$ for the second equation, we have
\else
    一番目の式の両辺に3を乗じ、二番目の方程式については $s_k$ との内積をとることで、以下が得られます。
\fi
\begin{align*}
    3(f(x_k) - f(x_{k+1})) +3 s_k^\top \nabla f(x_{k+1}) & = \frac{3}{2} s_k^\top B_{k+1}^{\mathrm{C}} s_k - \frac{1}{2} s_k^\top (T_{k+1} s_k) s_k, \\
    -s_k^\top y_k                                        & = -s_k^\top B_{k+1}^{\mathrm{C}} s_k + \frac{1}{2} s_k^\top (T_{k+1} s_k) s_k.
\end{align*}
\ifEn
    By adding these and using $y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$, we eliminate the tensor term and obtain the scalar identity
\else
    これらを合計し、$y_k = \nabla f(x_{k+1}) - \nabla f(x_k)$ を使用することで、テンソル項が除去できて、以下の等式を得ます。
\fi
\begin{equation*}
    3(f(x_k) - f(x_{k+1}))
    + \frac{3}{2} s_k^\top (\nabla f(x_{k+1}) + \nabla f(x_k)) + \frac{1}{2} s_k^\top y_k
    = \frac{1}{2} s_k^\top B_{k+1}^{\mathrm{C}} s_k.
\end{equation*}
\ifEn
    Again, for some scalar $\sigma_k^\mathrm{C} \in \mathbb{R}$, we assume $\left( B_{k+1}^{\mathrm{C}} + \sigma_k^\mathrm{C} I \right) s_k = y_k$. Then, the previous equation yields
\else
    ここでも、あるスカラー $\sigma_k^\mathrm{C}$ に対して $\left( B_{k+1}^{\mathrm{C}} + \sigma_k^\mathrm{C} I \right) s_k = y_k$ と仮定します。そうすると、先の方程式は
\fi
\begin{equation*}
    3(f(x_k) - f(x_{k+1})) + \frac{3}{2} s_k^\top (\nabla f(x_{k+1}) + \nabla f(x_k)) = - \frac{\sigma_k^\mathrm{C}}{2} \left\lVert s_k \right\rVert^2,
\end{equation*}
\ifEn
    which means
\else
    つまり、
\fi
\begin{equation*}
    \sigma_k^\mathrm{C} = -\frac{6(f(x_k) - f(x_{k+1})) + 3 s_k^\top (\nabla f(x_k) + \nabla f(x_{k+1}))}{\left\lVert s_k \right\rVert^2}.
\end{equation*}
\ifEn
    Thus, the modified secant condition becomes
\else
    従って、以下の修正セカント条件が得られます。
\fi
\begin{equation*}
    B_{k+1}^{\mathrm{C}} s_k = y_k + \frac{6(f(x_k) - f(x_{k+1})) + 3 s_k^\top (\nabla f(x_k) + \nabla f(x_{k+1}))}{\left\lVert s_k \right\rVert^2} s_k.
\end{equation*}
\ifEn
    This is a cubic-augmented modified secant condition. Refer to \cref{fig:zhang_models} for an illustration.
\else
    これが三次項による修正セカント条件です。具体例として\cref{fig:zhang_models}も参照してください。
\fi

\ifEn
    \subsection{Other Curvature Related Methods}
\else
    \subsection{その他の曲率関連手法}
\fi

\ifEn
    There are several other topics related to obtaining the curvature pairs $s_k, y_k$. Agg-BFGS~\citep{berahasLimitedmemoryBFGSDisplacement2022} is an alternative approach to managing curvature information by aggregating data rather than discarding the oldest information and adding the newest.
\else
    曲率情報を表すベクトルペア $s_k, y_k$ を求めることについては、他にもいくつかのトピックがあります。Agg-BFGS~\citep{berahasLimitedmemoryBFGSDisplacement2022} は、最も古い情報を破棄して最新のものを追加するのではなく、データを集約することにより曲率情報を管理する別のアプローチです。
\fi
\ifEn
    Multi-Secant~\citep{leeAdvancingMultiSecantQuasiNewton2025} extends the secant condition framework by maintaining multiple pairs of step and gradient difference vectors. In standard form we have seen, it is defined as
\else
    Multi-Secant~\citep{leeAdvancingMultiSecantQuasiNewton2025} とは、複数のステップと勾配差ベクトルのペアを維持することにより、セカント条件を拡張します。ここまでで見てきた標準的な形式では、次のように定義していました。
\fi
\begin{equation*}
    s_i = x_{i+1} - x_i, \quad y_i = \nabla f(x_{i+1}) - \nabla f(x_i). \quad (i = k-m, \ldots, k)
\end{equation*}
\ifEn
    In contrast, Multi-Secant centers all vectors around the latest iterate:
\else
    一方、Multi-Secantでは、すべてのベクトルを最新の点を中心としています。
\fi
\begin{equation*}
    s_i = x_{k+1} - x_i, \quad y_i = \nabla f(x_{k+1}) - \nabla f(x_i). \quad (i = k-m, \ldots, k)
\end{equation*}
\ifEn
    This approach can lead to better approximations in some cases.
\else
    このアプローチによって、場合によってはより良い近似が得られることもあります。
\fi
