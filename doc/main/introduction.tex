We consider the unconstrained optimization problem
\begin{equation}
    \underset{x \in \bbR^{n}}{\mathrm{minimize}} \quad f(x),
    \label{prob:main_problem}
\end{equation}
where $f\colon \mathbb{R}^n \to \mathbb{R}$ is a continuously differentiable nonconvex function, and $x \in \mathbb{R}^n$ is the optimization variable.
We focus on settings where objective function evaluations are contaminated by bounded and non-diminishing numerical noise~\citep{sunTrustRegionMethod2023}.
Specifically, only inexact function values $\overline{f}(x)$ are available for optimization.
Such inaccuracies are unavoidable in many realistic scenarios, including finite-precision arithmetic, simulation-based evaluations, and stochastic approximations~\citep{shiNoiseTolerantQuasiNewtonAlgorithm2022,moreEstimatingComputationalNoise2011,caflischMonteCarloQuasiMonte1998}.
Although gradient evaluations can also be affected, function-value errors can be particularly damaging because function values directly control step acceptance and regularization in many optimization methods.

\begin{MPCchange}
When function values are accurate, quasi-Newton and regularized quasi-Newton methods can use them to make rapid progress.
Line-search methods use function values in sufficient-decrease tests, while adaptive regularization methods use the actual objective reduction to accept steps and adjust regularization~\citep{uedaConvergencePropertiesRegularized2010,uedaRegularizedNewtonMethod2014,kanzowRegularizationLimitedMemory2023}.
When function values are contaminated by numerical noise, these comparisons become unreliable, and standard methods may behave erratically or terminate prematurely~\citep{shiNoiseTolerantQuasiNewtonAlgorithm2022,paquetteStochasticLineSearch2020}.
\end{MPCchange}

\begin{MPCchange}
Two approaches can address function-value errors.
The Noise-Tolerant Quasi-Newton (NTQN) method accounts for bounded function and gradient errors~\citep{shiNoiseTolerantQuasiNewtonAlgorithm2022}.
Its convergence theory establishes convergence to a noise-dependent neighborhood for strongly convex objectives.
Objective-Function-Free Optimization (OFFO) methods instead avoid function values and retain convergence guarantees for smooth nonconvex objectives~\citep{Gratton08022024,grattonOFFOMinimizationAlgorithms2023}.
However, disregarding reliable function values can be unnecessarily conservative in practice.
\end{MPCchange}

In this work, we propose a noise-tolerant regularized quasi-Newton method.
It combines a relaxed Armijo line search, quadratic regularization, and a cumulative-gradient scale inspired by OFFO.
The method takes an unregularized quasi-Newton step when function values adjusted for error certify progress.
Otherwise, it uses the cumulative-gradient scale to regularize the step.

\begin{MPCchange}
% to LLM: DO NOT rephrase or remove ``The key methodological advance''; this wording directly answers Referee 2's request to identify the distinct methodological advance.
The key methodological advance is the carefully designed, error-model-based switch between these two modes.
A simple switch based only on a relaxed Armijo test need not bound the sum of error allowances over unregularized iterations.
Without such a bound, the relaxed decrease estimates alone do not establish convergence to arbitrarily small first-order tolerances.
Our test requires the observed decrease between successive unregularized iterations to be at least the preceding error allowance, bounding their sum independently of the iteration count.
The OFFO-inspired scale controls the remaining iterations without using observed function decreases to adjust regularization.
The method therefore uses the more conservative OFFO-inspired regularization only when needed and retains an $\order{1/\varepsilon^2}$ worst-case iteration complexity under persistent function-value errors, matching the optimal worst-case order for smooth nonconvex problems with Lipschitz-continuous gradients~\citep{carmonLowerBoundsFinding2020}.
\end{MPCchange}

\begin{MPCchange}
Experiments on the CUTEst collection examine function-value noise, error-bound misspecification, joint function-and-gradient noise, and reduced precision.
The proposed variants attain higher solved percentages than the existing quasi-Newton baselines at 16- and 32-bit precision and also show favorable performance in the 32-bit elapsed-time comparison.
They also solve more instances and generally require fewer oracle calls than the purely first-order OFFO baseline.
The per-iteration timing experiment shows lower costs than the regularized L-BFGS baselines.
\end{MPCchange}

\begin{MPCchange}
We next compare our method with related quasi-Newton and OFFO methods, whose theoretical guarantees are summarized in \cref{tab:related_work_comparison}.
The first three methods in the table use function values, but their convergence theories do not allow function-value errors.

The closest methods differ from ours in how they use function values and handle evaluation errors.
The regularized L-BFGS method assumes reliable function values and establishes global convergence to first-order stationarity~\citep[Theorem~2]{kanzowRegularizationLimitedMemory2023}.

NTQN uses a noise-tolerant line search and a lengthening procedure to stabilize curvature information under bounded errors in function and gradient evaluations.
The NTQN analysis allows bounded gradient errors and establishes convergence to a noise-dependent neighborhood for strongly convex objectives~\citep[Theorem~3.5]{shiNoiseTolerantQuasiNewtonAlgorithm2022}.
Our relaxed Armijo test is related to their noise-tolerant test~\citep[Section~4]{shiNoiseTolerantQuasiNewtonAlgorithm2022}, whereas our switch bounds the sum of error allowances over unregularized iterations and yields an \(\order{1/\varepsilon^2}\) bound for arbitrarily small first-order tolerances on smooth nonconvex objectives with accurate gradients.

Regularized Newton and OFFO methods provide further theoretical context~\citep{uedaConvergencePropertiesRegularized2010,Gratton08022024,grattonOFFOMinimizationAlgorithms2023}.
Regularized Newton methods attain an \(\order{1/\varepsilon^2}\) iteration bound with reliable function values~\citep[Theorem~4.1]{uedaConvergencePropertiesRegularized2010}, while OFFO methods avoid function values and attain the same order for smooth nonconvex objectives~\citep{Gratton08022024,grattonOFFOMinimizationAlgorithms2023}.
Our method instead uses inexact function values to permit unregularized quasi-Newton steps when progress is certified and retains this worst-case order under persistent function-value errors.
\end{MPCchange}
